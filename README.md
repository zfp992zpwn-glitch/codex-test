# 投資ポートフォリオ管理アプリ（初心者向け）

このアプリは、**HTML / CSS / JavaScript だけ**で作られた、シンプルな投資ポートフォリオ管理ツールです。
サーバーやログインは使わず、データはあなたのブラウザの `localStorage` に保存されます。

## できること

1. 保有銘柄の追加・編集・削除
   - 銘柄名
   - 種類（投資信託、ETF、個別株、暗号資産、現金）
   - 現在の評価額
   - 毎月の積立額
   - メモ
2. 銘柄一覧表示
3. 総資産額の自動計算
4. 種類別の資産配分を円グラフで表示（Chart.js）
5. 毎月の総資産額の推移を折れ線グラフで表示
6. 銘柄ごとの評価額推移を折れ線グラフで表示

## 使い方

1. `index.html` をブラウザで開く
2. 「保有銘柄を追加・編集」で入力して保存
3. 「毎月の総資産推移」に月と総資産額を入力
4. 「銘柄ごとの評価額推移」で銘柄・月・評価額を入力
5. 編集したい銘柄は「編集」、消したい銘柄は「削除」

> メモ: `localStorage` は同じブラウザ内に保存されます。別のブラウザやシークレットモードでは共有されません。

## ファイル構成（初心者向け）

- `index.html`
  - 画面の部品（フォーム、一覧、グラフ表示エリア）を定義
  - Chart.js を CDN で読み込み
- `styles.css`
  - 見た目を調整（白ベース、カード型、スマホ対応）
- `app.js`
  - データ管理、`localStorage` 保存、一覧表示、編集/削除
  - 円グラフ・折れ線グラフの描画処理

## 補足

- データ保存先のキー:
  - `portfolio_assets`
  - `portfolio_monthly_totals`
  - `portfolio_asset_history`
- ローカルだけで完結するため、まずは学習用途・個人利用に向いています。
