# 人生逃げ切り診断

年収・税金・投資・副業・労働単価から、**何歳で週5労働から逃げられるか**を逆算する静的Webアプリです。  
HTML / CSS / JavaScript + Chart.js で動作し、データは `localStorage` に保存されます。

## 使い方
1. 基本情報（年齢、資産、想定年利）を入力
2. 職業ルートを選択（初期値が自動反映、すべて手動編集可）
3. 年齢フェーズ別年収を入力
4. 税設定を「自動推定」または「手動」に設定
5. 支出を「直接入力」または「内訳自動計算」に設定
6. 投資額を「手動」または「自動計算」に設定
7. 副業設定・労働単価を入力
8. 診断結果・グラフを確認

## 計算式
- 年間手取り = 年収 × 手取り率
- 月手取り = 年間手取り ÷ 12
- 月生活費 = 家賃 + 固定費 + 趣味交際費 + 年間特別支出 ÷ 12（自動モード）
- 毎月投資可能額 = max(月手取り - 月生活費, 0)（自動モード）
- 資産収入 = 資産額 × 4% ÷ 12
- 副業手取り = 副業月収 × 副業手取り率
- 労働脱出率 = (資産収入 + 副業手取り) ÷ 月生活費 × 100
- 不足額 = 月生活費 - 資産収入 - 副業手取り
- 必要労働日数/月 = 不足額 ÷ 1日あたりの手取り収入
- 必要労働日数/週 = 必要労働日数/月 ÷ 4

## 税金・社会保険について（重要）
このアプリの税金・社会保険は**簡易推定**です。  
正確な税額計算を行うものではありません。実務上の意思決定では税理士・社労士等の確認を推奨します。

## ランクの意味
- S：もう労働に人生を握られていない
- A：週1〜2勤務で十分
- B：週3勤務ならかなり自由
- C：副業か投資額の強化が必要
- D：まだ労働依存が強い
- E：このままだと普通に週5労働

## GitHub Pagesで公開
1. このリポジトリを GitHub に push
2. GitHub の `Settings` → `Pages`
3. `Deploy from a branch` を選択
4. Branch を `main`（または利用ブランチ） / Folder を `/root` に設定
5. 保存後、発行URLにアクセス

## 備考
- 暴落シミュレーションを内蔵（30歳で-30%、33歳で-50%、積立継続前提）
- ブラウザの `localStorage` を使うため、同一ブラウザで入力データが保持されます
