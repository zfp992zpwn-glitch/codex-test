# 投資ポートフォリオ管理アプリ（GitHub Pages対応）

HTML/CSS/JavaScriptのみで動く、ローカル保存型アプリです。データは `localStorage` に保存されます。

## 評価額の計算方法
- 投資信託:
  - 評価額 = 保有口数 × 現在の基準価額 ÷ 10,000
  - 取得額 = 保有口数 × 平均取得基準価額 ÷ 10,000
  - 損益 = 評価額 - 取得額
  - 損益率 = 損益 ÷ 取得額 × 100
- ETF・個別株:
  - 評価額 = 保有数量 × 現在価格
  - 取得額 = 保有数量 × 平均取得単価
- 暗号資産:
  - 評価額 = 保有数量 × 現在価格
  - 取得額 = 保有数量 × 平均取得単価
- 現金:
  - 評価額 = 金額
  - 損益 = 0
  - 損益率 = 0

## 投資信託の注意
投資信託は「基準価額」が1万口あたりで表示されることが多いため、上記の ÷10,000 が必要です。基準価額は証券会社画面を見て手入力します。

## 価格取得について
- Bitcoin / Ethereum: CoinGecko API からJPY価格を取得
- ETF / 個別株: Alpha Vantage API（GLOBAL_QUOTE）を利用
- APIキーは画面で入力して保存（`localStorage`）
- APIキーはコードに直接書かない
- 取得失敗時はエラーメッセージ表示し、手入力価格をそのまま使えます

## Alpha Vantage APIキー設定手順
1. Alpha Vantage でAPIキーを取得
2. アプリ画面の「Alpha Vantage APIキー」に貼り付け
3. 「APIキー保存」を押す
4. 「価格を更新」を押す

## GitHub Pagesで使うときの注意
- 静的サイトなので秘密情報の安全な保管先はありません
- APIキーをソースコードへ直書きしないでください
- 可能ならキー利用制限を設定してください

## マイグレーション対応
旧データ形式（`value` しかない等）を読み込んだ場合でも、新形式へ自動変換して壊れにくくしています。

## ファイル
- `index.html`: 画面
- `styles.css`: デザイン
- `app.js`: ロジック、価格取得、localStorage保存
