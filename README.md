# 投資ポートフォリオ管理アプリ（初心者向け）

HTML / CSS / JavaScript だけで動く、GitHub Pages対応の投資ポートフォリオ管理アプリです。  
データはブラウザの `localStorage` に保存されます。

## 主な改善点

- 銘柄種類ごとに評価額・取得額・損益・損益率を自動計算
- 「価格を更新」ボタンで一部銘柄の現在価格を自動取得
- 自動取得に失敗した場合も手入力価格をそのまま利用
- 総資産額の自動再計算
- 円グラフ（評価額ベース配分）と折れ線グラフ（総資産推移）の自動更新

## 評価額の計算方法

### 投資信託

- 評価額 = 保有口数 × 現在の基準価額 ÷ 10000
- 取得額 = 保有口数 × 平均取得基準価額 ÷ 10000
- 損益 = 評価額 - 取得額
- 損益率 = 損益 ÷ 取得額 × 100

### ETF・個別株・暗号資産

- 評価額 = 保有数量 × 現在価格
- 取得額 = 保有数量 × 平均取得単価
- 損益 = 評価額 - 取得額
- 損益率 = 損益 ÷ 取得額 × 100

### 現金

- 評価額 = 金額
- 損益 = 0
- 損益率 = 0

## 入力項目

### 投資信託

- 銘柄名
- 保有口数
- 平均取得基準価額
- 現在の基準価額
- 毎月の積立額
- メモ

### ETF・個別株・暗号資産

- 銘柄名
- ティッカー
- 種類
- 保有数量
- 平均取得単価
- 現在価格
- 毎月の積立額
- メモ

### 現金

- 銘柄名
- 金額
- 毎月の積立額
- メモ

## 価格取得の仕様

### Bitcoin / Ethereum（CoinGecko）

- 暗号資産のティッカーが `BTC` の場合は CoinGecko の `bitcoin` を参照
- 暗号資産のティッカーが `ETH` の場合は CoinGecko の `ethereum` を参照
- 価格は日本円（JPY）を取得

### 米国株・ETF（Alpha Vantage）

- 画面上で Alpha Vantage APIキーを入力して保存
- APIキーは `localStorage` に保存され、コードには埋め込まれません
- ティッカーごとに `GLOBAL_QUOTE` を使って価格取得

### 自動取得失敗時

- APIエラー、キー未設定、ティッカー未設定などの場合は
  既存の手入力価格を維持

## Alpha Vantage APIキー設定手順

1. Alpha VantageでAPIキーを取得
2. アプリ上部「価格更新設定」に貼り付け
3. 「APIキー保存」をクリック
4. 「価格を更新」で価格取得を実行

## GitHub Pagesで使う場合の注意点

- APIキーはブラウザに保存されるため、共有PCでは利用後に削除推奨
- 無料APIは呼び出し制限があるため、短時間での連続更新は失敗することがあります
- GitHub Pagesは静的配信のため、サーバー側秘匿キーは使えません

## データ保存先（localStorageキー）

- `portfolio_assets`
- `portfolio_monthly_totals`
- `portfolio_api_settings`
